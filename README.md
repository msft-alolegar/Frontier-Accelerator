# Frontier Accelerator: The Prompt Park

Welcome to the Jurassic-inspired Prompt Park, a habitat for prompts used in
Frontier Accelerator sessions. No dinosaur DNA required: explore, adapt, and
share what works.

## The field guide

- [Session prompt template](prompts/session-template.md) — a starting point for
  documenting a prompt and the session it supports.

## Add a specimen

1. Copy the [template](prompts/session-template.md) into `prompts/` and give it
   a descriptive filename, such as `prompt-design-workshop.md`.
2. Fill in the session details, the prompt, and any instructions for using it.
3. Add a link to the new prompt in the field guide above.

Keep prompts reusable: replace sensitive information with placeholders and
never commit secrets, credentials, or private session data.
